Visão Geral

Pontos de dados internos podem ser criados para monitorar valores específicos que controlam o funcionamento interno do Scada-LTS.

Valores de pontos a serem escritos

Este atributo monitora o número de valores de pontos que estão aguardando para serem escritos, refletindo a carga de trabalho do mecanismo de processamento em lote.

Threads de escrita dos valores de pontos

Este atributo indica as threads que estão lidando com o processo de escrita dos valores de pontos, fornecendo uma visão de como o sistema distribui a carga de trabalho da escrita em lote.

Itens de trabalho de alta prioridade

Este atributo rastreia os itens de trabalho de alta prioridade na fila de processamento, permitindo que os administradores identifiquem e respondam rapidamente a atrasos críticos no processamento.

Itens de trabalho de prioridade média

Este atributo reflete os itens de trabalho com um nível de prioridade média que estão aguardando execução, ajudando a avaliar a carga de trabalho rotineira do sistema.

Itens de trabalho agendados

Este atributo representa os itens de trabalho que estão agendados para serem executados em intervalos específicos, garantindo que as tarefas periódicas sejam realizadas em tempo hábil.

Altura máxima da pilha de threads

Este atributo mostra a profundidade máxima da pilha de threads, indicando o nível de operações aninhadas que podem impactar o desempenho ou revelar problemas potenciais.

Contagem de threads ativas

Este atributo monitora o número de threads ativas, oferecendo uma visão geral sobre a concorrência e a carga do sistema.

Para mais detalhes ou orientações de configuração, consulte a documentação do sistema ou entre em contato com o suporte.
