Description

The OPC Data Source allows the reading data from a OPC Server

Configuration

The OPC UA drivers uses the connection string:

opc.tcp://{Server Host}:{Server Port}/{Server Path}?{options}

All Data Source requires a Name, which may have any description.

The Server Host indicates the host from server.

The Server Port indicates the port from server.

The Server Path indicates the path from server.

The User indicates username to server.

The Password indicates password to server.

The Message Security applied to messages exchanged after handshake phase. Possible options are NONE, SIGN, SIGN_ENCRYPT. This option is effective only when securityPolicy turns encryption (anything beyond NONE).

The Security Policy applied to communication channel between driver and OPC UA server. Default value assumes. Possible options are:

  • NONE
  • Basic128Rsa15
  • Basic256
  • Basic256Sha256
  • Aes128_Sha256_RsaOaep
  • Aes256_Sha256_RsaPss

The Key Store Type type used to access keystore and private key, defaults to PKCS (for Java 11+). Possible values are between others jks, pkcs11, dks, jceks.

The Key Store File used to lookup client certificate and its private key.

The Key Store Password Java keystore password used to access keystore and private key.

The Channel Lifetime [ms] Time for which negotiated secure channel, its keys and session remains open. Value in milliseconds, by default 60 minutes.

The Session Timeout [ms] Expiry time for opened secure session, value in milliseconds. Defaults to 2 minutes.

The Negotiation Timeout [ms] Timeout for all negotiation steps prior acceptance of application level operations - this timeout applies to open secure channel, create session and close calls. Defaults to 60 seconds.

The Request Timeout [ms] Timeout for read/write/subscribe calls. Value in milliseconds.

The Max Message Size Maximum size of complete message.

The Default Timeout [ms][TCP] Timeout after which a connection will be treated as disconnected.

The Server Name shows which server are available for the data provided.

The Update Period indicates the update period from Data Source data.

The Creation Mode indicates how the OPC Tags will be created on the client. We have two options: Browse Tags - where all the Tags available in the Server will be displayed and Add Tags - where will be added a Tag available from Server

The Quantize will cause the data source startup to be delayed so that pollings occur at a "rounded" point in time (e.g. if polling is every 10 seconds, polls will occur on the 10th second, the 20th second, etc). Otherwise, polling will begin immediately.
