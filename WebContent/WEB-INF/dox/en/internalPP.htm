Overview

Internal data points can be created to monitor specific values that monitor the internal workings of Scada-LTS.

Point values to be written

This attribute monitors the number of point values that are waiting to be written, reflecting the workload of the batch processing mechanism.

Point value write threads

This attribute indicates the threads handling the writing process of point values, providing insight into how the system distributes the batch write workload.

High priority work items

This attribute tracks high priority work items in the processing queue, allowing administrators to quickly identify and respond to critical processing delays.

Medium priority work items

This attribute reflects the work items with a medium priority level that are pending execution, helping to gauge the routine load on the system.

Scheduled work items

This attribute represents work items that are scheduled to run at specific intervals, ensuring that periodic tasks are executed in a timely manner.

Maximum thread stack height

This attribute shows the maximum depth of the thread stack, indicating the level of nested operations that could impact performance or reveal potential issues.

Active thread count

This attribute monitors the number of active threads, offering insights into the overall concurrency and load of the system.

For further details or configuration guidance, please refer to the system documentation or contact support.
