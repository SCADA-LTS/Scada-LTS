Visión General

Se pueden crear puntos de datos internos para monitorear valores específicos que controlan el funcionamiento interno de Scada-LTS.

Valores de puntos a escribir

Este atributo supervisa el número de valores de puntos que están esperando ser escritos, reflejando la carga de trabajo del mecanismo de procesamiento en lotes.

Hilos de escritura de valores de puntos

Este atributo indica los hilos que gestionan el proceso de escritura de valores de puntos, proporcionando información sobre cómo el sistema distribuye la carga de trabajo de escritura en lotes.

Elementos de trabajo de alta prioridad

Este atributo rastrea los elementos de trabajo de alta prioridad en la cola de procesamiento, permitiendo a los administradores identificar y responder rápidamente a retrasos críticos en el procesamiento.

Elementos de trabajo de prioridad media

Este atributo refleja los elementos de trabajo con un nivel de prioridad media que están pendientes de ejecución, ayudando a evaluar la carga rutinaria del sistema.

Elementos de trabajo programados

Este atributo representa los elementos de trabajo que están programados para ejecutarse a intervalos específicos, asegurando que las tareas periódicas se realicen de manera oportuna.

Altura máxima de la pila de hilos

Este atributo muestra la profundidad máxima de la pila de hilos, indicando el nivel de operaciones anidadas que podría impactar el rendimiento o revelar problemas potenciales.

Conteo de hilos activos

Este atributo supervisa el número de hilos activos, ofreciendo una visión global sobre la concurrencia y la carga del sistema.
